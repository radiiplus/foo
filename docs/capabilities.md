# Systems capability audit

This tracks general FOO capabilities exposed by demanding systems libraries.
It is not a Stateful-specific feature list. "Partial" means the named API
exists but does not yet meet the full use case.

| Capability | Status | Current boundary |
| --- | --- | --- |
| Binary and streaming cryptographic hashing | Implemented | SHA-256 and BLAKE3 accept byte sequences and incremental chunks, return independent owned binary or hex results, and have explicit state cleanup. `checksum` provides separate direct and incremental CRC32C. |
| Streaming message authentication | Implemented | `crypto.auth/absorb/tag/check/discard` provide incremental HMAC-SHA256 over arbitrary bytes, repeatable 32-byte tags, constant-time tag verification, and explicit state cleanup. |
| HKDF key derivation | Implemented | `crypto.derive` implements HKDF-SHA256 extraction and expansion over binary secret, salt, and context, including empty salt, with the RFC 5869 limit of 8160 output bytes. |
| Constant-time byte comparison | Implemented | `crypto.compare` compares equal-length byte sequences without early exit based on byte values; differing lengths return false immediately and remain observable. |
| Hardware-assisted hashing | Implemented | Bundled BLAKE3 C sources dispatch to SSE2 on x86-64 or NEON on AArch64, with a portable fallback. Zig BLAKE3 uses target-selected SIMD lanes. SHA-256 and CRC32C retain portable implementations. |
| Owned bytes and read-only byte views | Implemented | Owned byte sequences and borrowed `sequence.view`, `memory.bytes`, and `file.view` ranges are public. The checker rejects uses after direct release, resize, close, or unmap, including aliases and returned views released by cleanup. |
| User-defined lifetime relationships | Implemented | `borrowing parameter` relates returned storage to an input, and `releasing parameter` declares owner invalidation. The checker rejects undeclared releases in ordinary function bodies and invalidates caller aliases and views after declared releasing calls, including error paths. |
| Compile-time assertions | Implemented | `eval { verify condition. }` rejects a false condition. |
| Type-derived compile-time constants | Implemented | `eval` folds `reflect[T].size` and `.alignment` for fixed-width scalars, pointers, slices, text, and C records using the selected target's pointer width. |
| Record field and layout introspection | Implemented | `eval` folds C-record `reflect[T].count`, `.offset(name or index)`, `.fieldname(index)`, and `.fieldtype(name or index)`; field types are returned as FOO type text. Source generation is tracked separately below. |
| Macros and controlled source generation | Implemented | `eval` performs constant work, and `build.tasks` has a structured `record` task that validates a type name, field identifiers, and primitive field types before emitting ordinary checked FOO source. Syntax macros and compiler plugins are outside this controlled generation contract. |
| Derive implementations | Implemented | Records and choices support checked `derives Equatable`, `Hash`, and `Ord` contracts for eligible components. `Hash` and `Ord` imply structural equality, and derived ordering is lexicographic. Persistence-specific derives are outside this general trait contract. |
| Derived specialized serializers | Implemented | `codec.encode[T]/decode[T]` generate specialized JSON conversion; `codec.pack[T]/unpack[T]` wrap the same type-specialized payload in a canonical length-prefixed byte frame with a decode limit and trailing-data rejection. The payload remains JSON, not a native binary field layout. |
| Atomic compare-and-swap and ordering | Implemented | `atomic.order` provides typed choices for `read/write/increase/decrease/exchange/commit/cas`; the original text calls remain for compatibility. Invalid operation/order pairs and compare failure orders return `InvalidOrder`. |
| Memory mapping | Implemented | `file.map/view` and `file.edit/mutable` expose bounded read-only and shared writable ranges on Windows and POSIX; both `file.persist` forms and `file.unmap` manage writable mappings, and later uses of borrowed views are rejected. |
| Cache and alignment hints | Implemented | `arch.prefetch/stage` provide advisory byte-slice hints; `memory.reserve/aligned` guarantee and check power-of-two address alignment, including after growth. `c record ... aligned to N` raises record alignment on C and Zig. |
| Typed pointer reinterpretation | Implemented | `memory.cast[T]` borrows an owned allocation as an integer, float, or scalar-only C record after checking allocator provenance, extent, alignment, and pointer arithmetic. The caller supplies initialized, valid `T` bytes and keeps the owner alive; ordinary FOO code cannot dereference the pointer, which is intended for native interop. |
| Filesystem storage operations | Implemented | Positioned I/O, exclusive create and update, truncation, preallocation, advisory locks, free-space and allocation-unit queries, metadata snapshots, and exclusive temporary files are public. |
| Crash and failure injection | Implemented | `process.exit/abort` terminate child processes for crash tests; `testing.fault/clear` inject one-shot partial writes, sync errors, and pre-rename replacement errors for the current thread. |
| Native ABI and platform capabilities | Implemented | C interop and target selection are complemented by `platform.page/width/alignment/little` for runtime page size, pointer width, maximum C alignment, and byte order, plus `platform.supports` for named hosted capabilities. This describes the selected host runtime, not arbitrary cross targets. |
| Structured system errors | Implemented | `issue.create/wrap` carry category, operation, named cause, and context; owned `issue` trails preserve ordered operation frames and original causes. Text fields borrow caller storage, and callers attach context explicitly around the short named tags in `failable T`. |
| Task cancellation | Implemented | `task.cancel/halt` request cooperative cancellation; callbacks check `task.cancelled`, nested scopes and pools inherit the request, new work is rejected, and queued pool callbacks are skipped. `join/wait` still synchronize completion. |
| Resource accounting | Implemented | `resource.files/mapped/threads` count live native handles and mapped bytes; `tasks/pending` count accepted callbacks and work not yet started, and `heap` counts tracked FOO-owned buffers and explicit allocations. Values are snapshots, not synchronization primitives. |
| Structured metrics | Implemented | `metric` owns synchronized counters, gauges, and bounded histograms with checked arithmetic, named instruments, and close. `metric.export` returns an independently owned JSON snapshot with histogram bounds and buckets. Histogram buckets are inclusive of their upper bound and include overflow. |
| Nested tracing spans | Implemented | `trace.begin/finish` track monotonic durations, parent IDs, labels, and the current span per thread. Spans finish in LIFO order on their creating thread and require close; export remains application-defined. |
| POSIX process limits | Implemented | `limit.available/soft/hard/set` query and update soft file-descriptor, address-space, CPU-time, and stack limits through the host OS. Unlimited values map to the maximum unsigned value. Windows and unsupported kinds report unavailability. |
| Portable binary integer codecs | Implemented | `binary.encode/decode` use canonical unsigned LEB128 with checked overflow and malformed-input rejection; `binary.fixed/parse` use checked 1-8 byte little- or big-endian values. |
| Signed ZigZag variable integers | Implemented | `zigzag.encode/decode` map signed 64-bit integers through ZigZag and canonical LEB128, including both signed limits; decoding returns the next offset and rejects malformed, overflowing, or nonminimal input. |
| Canonical hexadecimal byte codec | Implemented | `hex.encode/decode` convert arbitrary bytes to lowercase hex and back, including empty values; decoding rejects odd lengths, uppercase, and non-hex characters. Results are independently owned. |
| Canonical Base64url byte codec | Implemented | `base64.encode/decode` encode arbitrary bytes without padding using the URL-safe alphabet; decoding rejects padding, whitespace, other alphabets, invalid lengths, and nonzero unused tail bits. Results are independently owned. |
| Bit-packed binary flags | Implemented | `packing.bits/expand` use least-significant-bit-first groups of eight for zero/one byte flags; decoding requires an explicit flag count, exact byte length, and zero unused high bits. Results are independently owned. |
| Canonical byte run-length codec | Implemented | `packing.runs/unroll` encode maximal runs as count-byte pairs with counts from 1 to 255; decoding rejects truncated, zero-count, or nonmaximal runs and enforces a caller output limit. |
| Sorted unsigned delta codec | Implemented | `packing.deltas/restore` encode nondecreasing unsigned values as canonical LEB128 differences from zero; decoding enforces an item limit and rejects malformed varints and sum overflow. |
| Bounded length-prefixed frames | Implemented | `frame.pack/read` use canonical length prefixes, caller-supplied decode limits, checked ranges, owned payloads, and next offsets. |
| Checksummed binary blocks | Implemented | `block.pack/read` append little-endian CRC32C, reject truncated or corrupt blocks before allocating an owned payload, and enforce decode limits. CRC32C is not authentication. |
| Ordered binary search | Implemented | `sequence.lower/upper/search` find insertion boundaries and the first equal element in O(log n) comparisons on ascending sorted input. |
| Stable generic sorting | Implemented | `sequence.sort[T]` returns an independent stable ascending copy in O(n log n) comparisons with O(n) scratch storage. |
| Stable sorted merge | Implemented | `sequence.merge[T]` combines two ascending inputs in O(n + m) comparisons into one independently owned result; equal values from the left input precede equal values from the right. |
| Sorted sequence union | Implemented | `sequence.unite[T]` combines two ascending inputs into a sorted, duplicate-free, independently owned union in O(n + m) comparisons. |
| Sorted sequence intersection | Implemented | `sequence.intersect[T]` returns shared distinct values from two ascending inputs in O(n + m) comparisons with independent storage. |
| Sorted sequence difference | Implemented | `sequence.difference[T]` returns distinct values present only in the ascending left input in O(n + m) comparisons with independent storage. |
| Equality-based set union | Implemented | `set.unite[T]` preserves left insertion order, appends right-only members in their order, and returns independent storage without requiring `Ord`. |
| Equality-based set intersection | Implemented | `set.intersect[T]` returns shared members in left insertion order with independent storage and only an `Equatable` constraint. |
| Equality-based set difference | Implemented | `set.difference[T]` returns left-only members in left insertion order with independent storage and only an `Equatable` constraint. |
| Equality-based symmetric difference | Implemented | `set.symmetric[T]` returns left-only members followed by right-only members in insertion order with independent storage. |
| Equality-based subset check | Implemented | `set.subset[T]` checks that every left member appears in right without allocating; the empty set is a subset of every set. |
| Stable sequence partition | Implemented | `sequence.partition[T]` evaluates its predicate once per element, preserves order in both independently owned results, and uses O(n) work and scratch storage. |
| Compact bitmaps | Implemented | `bitmap` stores 64 bits per word, checks bounds, counts set bits, and returns independent updated values. |
| Persistent bitmap algebra | Implemented | `bitmap.merge/intersect/difference` return independent bitmaps with union, intersection, and left-minus-right bits; unequal logical lengths fail with `Shape`. Inputs remain unchanged. |
| Bitmap prefix rank | Implemented | `bitmap.rank(value, index)` counts set bits strictly before a checked index, including `index` equal to the bitmap length. It scans packed words without allocating. |
| Bitmap ordinal select | Implemented | `bitmap.select(value, ordinal)` returns the position of a zero-based set bit, or null when the ordinal is absent. It scans packed words without allocating. |
| Persistent bitmap toggle | Implemented | `bitmap.toggle` flips one checked logical bit into an independently owned bitmap without changing the source. |
| Logical bitmap complement | Implemented | `bitmap.invert` returns an independent complement over exactly the logical length; unused high bits in a partial final word stay zero. |
| Persistent bitmap symmetric difference | Implemented | `bitmap.symmetric` returns independently owned bits set in exactly one input; unequal logical lengths fail with `Shape`. |
| Next set-bit scan | Implemented | `bitmap.next(value, from)` finds the first set bit at or after `from`, or null when absent or beyond the logical length. |
| Previous set-bit scan | Implemented | `bitmap.previous(value, before)` finds the last set bit strictly before `before`, or null when absent or beyond the logical length. |
| Priority heaps | Implemented | `heap` exposes typed persistent minimum-priority queues with insertion, removal, bulk construction, merge, root replacement, pop with value, and sorted extraction. Updates own copied storage. |
| Linear-time heap construction | Implemented | `heap.build[T]` copies an arbitrary sequence and restores minimum-heap order bottom-up in O(n) work. |
| Linear-time heap merge | Implemented | `heap.merge[T]` copies two valid heaps, checks combined length overflow, and heapifies the combined values in O(n + m) work. |
| Persistent heap root replacement | Implemented | `heap.replace[T]` replaces a nonempty heap's minimum in independent storage and restores heap order; an empty heap fails with `Empty`. |
| Heap pop with removed value | Implemented | `heap.pop[T]` returns both the removed minimum and an independent remaining heap in one result; an empty heap fails with `Empty`. |
| Sorted heap extraction | Implemented | `heap.sorted[T]` drains a private copy into an independent ascending sequence in O(n log n) comparisons while leaving the source unchanged. |
| Bounded byte deque | Implemented | `ring` owns a fixed-capacity byte buffer with constant-time insertion, removal, and peeking at both ends; full insertion returns false and empty removal fails. Calls are synchronized and handles require close. |
| Bit-packed Bloom filters | Implemented | `bloom` owns a configurable bitset for arbitrary byte keys, supports incremental insert and membership checks, and guarantees no false negatives until close; false positives remain possible. Its hash is noncryptographic. |
| Stable unsigned radix sort | Implemented | `radix.sort` returns an independent ascending sequence of 64-bit unsigned values using eight stable byte passes, linear work per pass, and linear scratch storage. |
| Stable signed radix sort | Implemented | `radix.signed` returns an independent ascending sequence of 64-bit signed values, including both limits, using eight stable byte passes and O(n) scratch storage. |
| Binary codecs and algorithms | Implemented | Integer, hex, Base64url, bit-packed flag, run-length, and sorted delta codecs; bounded frames and CRC32C blocks; sorted search, stable merge, set operations, stable partition, radix sorting, and `sequence.unique` for ascending inputs; JSON, bitmaps, heaps, byte rings, Bloom filters, and an ordered search tree are public. This is a bounded library of algorithms, not a general algorithm catalog. |
| Storage data structures | Implemented | Equality-based persistent sets with algebra and subset checks, compact bitmaps with algebra and rank/select, priority heaps, byte rings, Bloom filters, and a persistent packed ordered search tree are public. Tree lookup and rank are logarithmic; immutable updates copy values in linear time. |
| Time primitives | Implemented | `time.instant` is monotonic for elapsed measurement; `time.stamp` is UTC/POSIX nanoseconds since 1970 for persistence, with checked `between` arithmetic. `calendar` supplies validated civil dates and fixed offsets. |
| Process identity | Implemented | `process.id/parent` query current and parent process IDs; `process.identity` queries a spawned child's ID while its handle remains open. IDs may be reused after a process exits. |
| Spawned child lifecycle | Implemented | `process.spawn/active/wait/kill/close` launch directly with typed arguments, cache exit status, terminate, reap, and explicitly close owned child handles on Windows and POSIX. Process groups remain separate work. |
| Child standard-stream pipes | Implemented | `process.pipe` launches with separate stdin, stdout, and stderr; `write` accepts binary partial writes, `seal` closes stdin, and `read` returns one bounded owned binary chunk from `"output"` or `"error"`. `release` frees returned bytes and `close` closes remaining pipes. |
| Cancellable one-shot timers | Implemented | `timer.create/arm/wait/cancel/close` use monotonic deadlines, support rearming, wake a blocked waiter on cancellation, and release owned resources. One waiter may wait per timer. |
| Runtime SIMD and automatic CPU vectorization | Implemented | `arch.runtime` detects usable CPU features, `cpu.add` dispatches byte addition, and hosted release builds automatically vectorize independent contiguous 32-bit and 64-bit decimal map loops. Length, overlap, start, and CPU checks preserve the original scalar loop when vector execution is unsuitable. |
| Online logical CPU count | Implemented | `topology.count` reports the host's online logical processor count on Windows and POSIX. It may differ from the CPUs allowed to this process. |
| Current processor identity | Implemented | `topology.current` reports the calling thread's OS logical processor ID on Windows and Linux; on Windows, IDs encode processor group and group-local number. Other POSIX targets return `MissingValue`. |
| Scoped thread affinity | Implemented | `topology.pin/restore` save, apply, and restore a calling thread's affinity on Windows and Linux. Restore must run on that thread and rejects repeated calls; Linux CPU IDs must fit `CPU_SETSIZE`, and the OS may reject an unavailable processor. `task.affinity` now applies native affinity on Zig as well as C. |
| CPU topology and NUMA placement | Implemented | `topology.nodes/node` discover NUMA nodes and map OS CPU IDs on Windows and Linux; `place/restore` scope thread affinity to an available CPU in a requested node. Unsupported hosts report `MissingValue`; memory allocation policy is separate. |
| Persistent memory | Implemented | Shared writable file mappings expose whole-map `file.persist(mapping)` and bounded `file.persist(mapping, offset, length)` flushes; both request synchronous page flush and file synchronization on Windows and POSIX. This is a durability request for file-backed memory, not a persistent-memory device or power-loss guarantee. |

## Broader systems layers

These capabilities are shared needs for network services, games, tooling,
storage, and scientific software. The status describes the public FOO surface,
not platform facilities used internally by the runtime.

| Capability | Status | Current boundary |
| --- | --- | --- |
| Datagrams and socket addresses | Implemented | Typed IPv4/IPv6 endpoints, binary UDP packets, typed sender addresses, connected UDP, broadcast, and multicast controls are public. |
| UDP unicast hop limits | Implemented | `net.unicast` sets a checked IPv4 TTL or IPv6 unicast hop limit from 1 to 255 and reports the effective value. |
| UDP traffic class | Implemented | `net.traffic` sets a checked IPv4 TOS or IPv6 traffic class byte and reports the effective value; platforms may restrict nonzero classes. |
| UDP socket buffers | Implemented | `net.buffer/capacity` set and query send or receive capacity, reporting the effective OS value, which may differ from the request. |
| TCP socket timeouts | Implemented | `net.timeout` sets send or receive timeouts on owned TCP connections, reports the effective OS value in milliseconds, and accepts zero to disable a timeout. Requests above 2,147,483,647 ms fail. |
| TCP socket buffers | Implemented | `net.provision/allocation` set and query send or receive capacity on owned TCP sockets, returning the effective OS size; zero and values above 2,147,483,647 fail when setting. |
| TCP unicast hop limits | Implemented | `net.lifetime` sets a checked IPv4 TTL or IPv6 unicast hop limit from 1 to 255 and reports the effective OS value. |
| TCP traffic class | Implemented | `net.priority` sets a checked IPv4 TOS or IPv6 traffic class byte and reports the effective OS value; platforms may restrict nonzero classes. |
| UDP socket timeouts | Implemented | `net.expiry` provides the same bounded, effective-value send and receive timeout contract for owned UDP sockets; a timed-out operation returns `IoFailure`. |
| DNS and network discovery | Implemented | `dns` exposes A, AAAA, CNAME, NS, PTR, MX, SRV, and TXT record sets with TTLs; `adapter` and `route` expose owned interface and routing snapshots. |
| Advanced DNS resolution | Implemented | `dns.query(host, "txt")` returns TXT records through the system resolver, concatenating each record's character strings into bounded text. Resolver override and cancellable asynchronous lookup are outside this synchronous API. |
| Generic TLS | Implemented | `tls.available/connect/send/receive/timeout/close` provide owned client TLS streams for arbitrary TCP protocols using a loaded OpenSSL runtime, default trust roots, peer and hostname verification, and a bounded handshake. TLS server wrapping and custom trust stores are outside this client contract. |
| Local IPC and shared memory | Implemented | `ipc.create/join/view/edit/lock/unlock/close` provide named file-backed shared regions with exclusive creation, shared writable mappings, and advisory whole-region synchronization on Windows and POSIX. Local sockets, process-shared semaphores, and wait/wake events remain separate APIs. |
| Event polling and timers | Implemented | `poll` combines TCP and UDP readiness, child exit readiness, and one-shot monotonic deadlines under unique tokens; `timer` provides separate cancellable timers. Child registrations remain ready until removed. Poller mutation is serialized by the caller; user events are outside this API. |
| TCP readiness polling | Implemented | `poll.tcp` registers owned TCP connections or listeners for receive or send readiness with unique tokens; registrations persist until removed, and bounded waits return ready tokens or zero on timeout. |
| UDP readiness polling | Implemented | `poll.udp` registers owned UDP sockets for receive or send readiness in the same bounded poller; closed registered sockets fail the wait until removed. |
| Poller deadline events | Implemented | `poll.deadline` registers one-shot monotonic millisecond deadlines alongside sockets; zero-delay deadlines fire immediately, fired tokens are removed, and `poll.close` leaves sockets owned by their callers. |
| Virtual memory | Implemented | `virtual.reserve/commit/protect/decommit/load/store/release` manages whole page-backed regions with checked access and none, read, read/write, or read/execute protection; file mappings support writable views and flushing. |
| Directory and file discovery | Implemented | `file.scan` enumerates one directory; `file.walk` traverses recursively without following links; `file.metadata` snapshots kind, size, read-only status, and timestamps; `file.temporary` creates an exclusive file. |
| Process lifecycle and OS events | Implemented | Process identity, owned child launch, status, named signaling, kill, reaping, child standard-stream pipes, POSIX resource limits, and child exit polling are public. `signal` supports kill and terminate on Windows and POSIX, plus interrupt and hangup on POSIX; process groups are separate. |
| Bounded child wait | Implemented | `process.poll` waits up to 4,294,967,294 ms for an owned child, returns false on timeout, and caches completion so `wait` still returns the exit status. Zero is a nonblocking check. |
| Dynamic libraries | Implemented | `dylib.open/lookup/call/discard/close` load a native shared library, resolve a symbol with the declared 64-bit unary C ABI, invoke it, and unload it. Symbols are invalid after close; other C signatures are not covered by this contract. |
| CPU and device capabilities | Implemented | `arch.runtime` queries usable SIMD features; `topology.count/allowed/current/nodes/node/pin/place` expose online and eligible CPUs, NUMA mapping, and scoped affinity on supported hosts. `gpu.available/open/name/supports/capacity` discover Vulkan compute devices, and `gpu.view/edit` borrow coherent host-visible buffer memory. Explicit DMA ownership is outside this contract. |
| Streaming compression | Implemented | `compress.encode/decode` stream independent gzip or zlib members through `io.stream` with a four-byte length frame, bounded input chunks, caller limits for compressed frames and output blocks, and truncation rejection. `pack/unpack` retain single-value interoperability. |
| Broader cryptography and entropy | Implemented | Binary SHA-256 and BLAKE3, HMAC-SHA256, HKDF-SHA256, constant-time comparison, secure random bytes, Ed25519, and Argon2id are public. Binary AEAD selects XChaCha20-Poly1305 or AES-256-GCM with availability checks; 32-byte AEAD keys have locked, wiped storage; labeled keyed-BLAKE3 test streams are deterministic and bounded. |
| Telemetry and resource limits | Implemented | Live resource counters, synchronized metrics with owned JSON export, thread-local spans, and POSIX process-limit queries and soft-limit controls are public. Span propagation, Windows process-limit controls, and hard-limit changes are outside this scoped interface. |
| Advanced network and device I/O | Implemented | TCP and UDP timeouts, hop limits, traffic class, and buffer sizing are public; `net.egress` selects or clears an IPv4 UDP egress adapter by checked OS index where supported. Raw packets, zero-copy transfers, io_uring, RDMA, and direct GPU interop are outside this socket-control contract. |

## Hardware and parallel computation

The [hardware design goal](hardware.md) tracks portable numerical semantics,
CPU SIMD, GPU execution, and future accelerators. The table distinguishes
current support from the remaining roadmap.

| Capability | Status | Current boundary |
| --- | --- | --- |
| Vector lane indexing | Implemented | `permute`, checked vector-lane `gather`, and checked vector-lane `scatter` run on C and Zig; duplicate scatter indices resolve in source order. |
| Dense CPU matrix and tensor values | Implemented | The `matrix` and `tensor` modules provide owned row-major decimal values, checked shapes, and portable CPU operations. |
| Rectangular matrix transpose | Implemented | `matrix.transpose` exchanges rows and columns, reorders row-major decimal values, and returns independently owned storage, including for empty dimensions. |
| Owned tensor reshape | Implemented | `tensor.reshape` checks the new shape's product against the value count and copies both shape and row-major values into an independent result without reordering elements. |
| Tensor axis permutation | Implemented | `tensor.permute` requires every source axis exactly once, checks rank and bounds, reorders row-major decimal values into a new owned shape, and handles scalar and empty tensors. |
| Rectangular matrix crop | Implemented | `matrix.crop` checks the row and column intervals, copies the selected rectangle in row-major order, and returns independently owned storage, including zero-sized regions. |
| Tensor axis crop | Implemented | `tensor.crop` checks one axis interval, preserves the other extents, copies row-major blocks into an independent tensor, and supports zero-length intervals. |
| Tensor axis concatenation | Implemented | `tensor.concat` requires matching ranks and nonjoined extents, checks joined extent overflow, and copies each operand's row-major blocks into an independent result. |
| Matrix row sums | Implemented | `matrix.sum(value, "row")` returns one independently owned decimal sum per row in O(rows + rows × columns) work; a row with zero columns sums to zero. |
| Matrix column sums | Implemented | `matrix.sum(value, "column")` returns one independently owned decimal sum per column in O(columns + rows × columns) work; a column with zero rows sums to zero. |
| Tensor axis sums | Implemented | `tensor.sum` removes one checked axis, sums its values in source order, and owns the resulting shape and row-major values. Reducing a zero-length axis yields zero-valued results, and reducing rank one yields a scalar. |
| Matrix elementwise product | Implemented | `matrix.hadamard` requires identical row and column extents, multiplies corresponding decimal cells, and returns independent row-major storage. |
| Explicit tensor broadcasting | Implemented | `tensor.broadcast` right-aligns source axes with a target shape, expands singleton axes and optional leading axes, rejects incompatible extents, and owns the expanded row-major values and shape. |
| Tensor elementwise product | Implemented | `tensor.hadamard` requires identical ranks and extents, multiplies corresponding decimal cells, and returns independent row-major storage without implicit broadcasting. |
| Build-target SIMD feature query | Implemented | `arch.target` reports selected-target `sse2`, `avx2`, `avx512f`, `fma`, `neon`, and `sve` support. |
| Runtime CPU execution | Implemented | `arch.runtime` checks CPU and OS support; `cpu.add` uses runtime AVX2/SSE2 or NEON selection with a scalar fallback, explicit output, and checked lengths and overlap. |
| Counted decimal loop vectorization | Implemented | Hosted C and Zig release builds transform independent 32-bit and 64-bit decimal sequence loops with constant or parameter starts, up to two reads, scalar operands, fill/copy, and up to two arithmetic steps in either scalar order. Runtime guards select AVX-512F on C, AVX2 or SSE2 on x86, and NEON on AArch64; the original checked loop handles short, overlapping, or invalid ranges. Zig 0.16 cannot compile the per-function AVX-512 path. |
| Automatic CPU vectorization | Implemented | The release optimizer recognizes the independent contiguous decimal map forms above without source annotations, reports its selection, and retains scalar execution for short ranges, unsupported CPUs, aliasing, invalid bounds, and dependent loops. Other loop forms and order-changing reductions are outside this contract. |
| Portable SIMD foundation | Implemented | Fixed-width vectors, masks, lane arithmetic and selection, shuffle/permute, reductions, and feature queries run on C and Zig. `simd` provides checked contiguous load/store for four-lane decimal32, unsigned32, and integer32 values and two-lane decimal64 values. Automatic map vectorization selects a supported CPU path; explicit vector operations do not promise one hardware instruction. |
| GPU host execution | Implemented | `gpu` discovers Vulkan compute devices, owns devices, buffers, and kernels, transfers bytes, decimal 32 sequences, or unsigned 32 sequences, binds arguments, and synchronously launches one-, two-, or three-dimensional ranges. |
| FOO GPU lowering | Implemented | A private `function ... for gpu` with decimal 32 and unsigned 32 sequence parameters, global/local/group and subgroup IDs, indexed reads and writes, straight-line decimal arithmetic, shared decimal workgroup storage, unsigned 32 atomic addition, a uniform barrier, and lane-zero broadcast lowers directly to SPIR-V. Unsupported effects and operations fail compilation. |
| GPU execution model | Implemented | Hosted C and Zig programs use `gpu.prepare`, checked bound buffers and workgroup sizes, `gpu.dispatch`, device feature and capacity queries, and synchronous completion. Shared storage and atomic requirements are checked before dispatch. |
| Multidimensional Vulkan dispatch | Implemented | `gpu.plane` and `gpu.volume` launch checked 2D/3D ranges; generated `gpu.index`, `gpu.local`, and `gpu.group` use row-major linear IDs. |
| Advanced GPU portability | Implemented | The Vulkan path requests MoltenVK portability extensions, exposes coherent mapped buffers, and now runs checked unsigned 32-bit buffer copy kernels alongside decimal 32 kernels on available compute devices. MoltenVK still requires a macOS build; asynchronous events, device-local staging, and a software kernel fallback remain outside this contract. |
| Parallel compiler lowering | Implemented | Typed vectors and automatic CPU decimal maps lower for hosted C and Zig; checked straight-line decimal arithmetic and unsigned 32-bit buffer copy GPU kernels lower to SPIR-V with unsupported effects rejected. General control flow and wider GPU numeric operations remain outside these kernel families. |
| Matrix, tensor, and accelerator model | Implemented | Dense decimal matrix and tensor libraries provide owned row-major shapes, transpose, reshape, permutation, crops, concatenation, reductions, broadcasting, elementwise products, matrix products, and rank-three `tensor.product` with singleton batch broadcasting. This is a CPU model; mixed precision, hardware matrix acceleration, tiling, and device placement are outside its contract. |

The public poller combines socket and child readiness with deadlines. User
events remain a future source; TLS and file-backed IPC have separate ownership
contracts. Each public capability should describe a
stable FOO operation and keep platform-specific controls available through
explicit native bindings when needed.

No persistence keywords, implicit durable variables, or database-specific
language constructs are planned. General type-safe systems primitives should
serve storage, networking, media, scientific computing, and other libraries.
